# Conditionals
:::warning
These docs are not completely finished yet. We're slowly working on expanding the documentation while we work on other things, so please be patient with us!
:::

The conditional blocks consist of the following blockset:
<img src="/img/docimages/conditionals.png" alt="Conditionals Blockset"></img>

These blocks are probably familiar to most people. But if you're not, that's why you came here, isn't it? They return true or false.

First off, the = and ≠ blocks. = means equals, and ≠ means not equals. Simple, isn't it? There's also < and >. < means less than, so `42 < 50` would return true, but `50 < 42` would return false. Other way around for >. Then, ≤ and ≥. ≤ means less than or equals to, and ≥ means greater than or equals to.
